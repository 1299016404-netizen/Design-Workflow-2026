# Figma Design Agent Acceptance Checklist

每个需求完成后都必须执行本清单。若任一关键项不通过，应返回对应步骤修正。

## 基础流程检查

- [ ] 已完整读取上游需求文档。
- [ ] 已识别所有需求条目。
- [ ] 已读取每个需求的 Figma 写入地址对应目标页面、节点或文件上下文。
- [ ] 已确认目标页面、目标位置和邻近模块，未凭空判断写入区域。
- [ ] 每个需求都已按 `需求类型` 正确路由。
- [ ] 新增需求已询问用户选择 `新样式` 或 `规范样式`。
- [ ] 新增需求在用户选择 `新样式` 或 `规范样式` 后，已调用 `benefit-layout-selector` skill 推荐 3 个排版方案。
- [ ] 用户已确认其中一个排版方案，且已记录方案名称、利益点数量、主次关系、参考图片路径和选择理由。
- [ ] 草稿图确认节点没有被跳过。

## 规范文件检查

- [ ] Figma 写入前已读取 `design-rules.md`。
- [ ] Figma 写入前已读取 `figma-design.md`。
- [ ] 文本写入优先使用 `PingFang SC`；如果加载或写入失败，已 fallback 到 `Alibaba-PuHuiTi`。
- [ ] 设计稿符合对应页面的宽度、圆角、底色、内边距、外边距和文字规范。
- [ ] 间距和边距符合 6px 体系。
- [ ] 页面和模块使用 auto layout。
- [ ] 画板未裁切内容。
- [ ] 没有固定高度导致文本、图片或模块溢出。

## 图标与素材检查

- [ ] 图标只来自 `figma-icons/`。
- [ ] 没有使用外部图标库、emoji 或 Figma 基础形状拼图标。
- [ ] 图标比例未被拉伸。
- [ ] 图标尺寸符合 12px、16px、20px、24px 体系。

## 新样式草稿图检查

仅适用于 `新增页面` 或 `新增模块` 且用户选择 `新样式` 的需求。

- [ ] 参考图来自 `style-library/` 或用户当前任务明确提供的图片。
- [ ] 风格提示词只提炼风格，没有照搬参考图内容。
- [ ] 草稿图由 `image_gen` 生成，并结合参考图风格提示词、需求内容、用户确认后的排版形式和 Figma 写入地址对应目标页面上下文。
- [ ] 草稿图表达了方案放入目标页面后的结构、比例、目标位置和邻近模块关系。
- [ ] 草稿图体现了用户确认的排版方案，包括利益点位置、主次关系和模块比例。
- [ ] 用户已确认草稿图方案。
- [ ] 已使用 `view_image` 查看确认后的草稿图。

## 透明切图检查

仅适用于新样式分支。

- [ ] 已使用 `transparent-icon-cutout` skill 从草稿图中提取可复用视觉元素。
- [ ] 真实摄影图片、商品实拍图、酒店/景点照片、地图截图、用户头像等真实图片没有进入透明抠图流程。
- [ ] 透明切图输出到 `icon-cutout/`。
- [ ] Figma 写入优先使用 `*-transparent-trimmed.png`。
- [ ] 透明切图背景透明，无明显绿底、灰底或矩形底残留。
- [ ] 主体未被裁切，边缘没有明显破损。
- [ ] Figma 设计稿中对应视觉元素确实来自透明切图。
- [ ] 透明切图在 Figma 中保持原始比例。
- [ ] 透明切图位置、层级、比例和视觉关系与草稿图一致。
- [ ] 没有用 SVG、基础形状、临时手绘或整张草稿图铺底替代透明切图。

## Figma 写入检查

- [ ] 写入使用 `use_figma`。
- [ ] 新增需求的 Figma 输出已参考用户确认后的排版形式，体现对应内容分组、主次层级和视觉比例。
- [ ] 图层命名清晰。
- [ ] 模块结构可编辑、可维护。
- [ ] 同类组件样式一致。
- [ ] 文本层级清晰，字号、字重、颜色符合规范。
- [ ] 模块级卡片没有违规描边或阴影。
- [ ] 页面中的新增内容没有遮挡已有内容。

## 新样式还原度检查

仅适用于新样式分支。

- [ ] 已截取 Figma 结果图。
- [ ] 已将 Figma 结果图与确认后的草稿图进行对比。
- [ ] 视觉结构与草稿图一致。
- [ ] 关键装饰图、插画或视觉符号来自透明切图并正确还原。
- [ ] 色彩氛围与草稿图一致，同时符合 `design-rules.md`。
- [ ] 文本和业务内容符合上游需求文档。

## 缺失资源处理

- [ ] `style-library/` 无匹配参考图时，已询问用户补充。
- [ ] `figma-icons/` 无匹配图标时，已明确说明缺少图标资源。
- [ ] 未自行联网找图、借用本地其他项目、临时生成图标或跳过资源缺失说明。
