# Figma 写入规则

## 1. 目标

本文档用于规范写入设计稿时的结构、布局、样式与命名方式，确保生成的设计稿：

- 结构清晰，便于维护
- 布局稳定，符合设计系统
- 样式统一，便于后续开发还原
- 写入结果准确，减少二次调整成本

---

## 2. 基本原则

1. **优先使用自动布局（Auto Layout）**
   - 除非明确需要绝对定位，否则所有容器都应使用自动布局。
   - 页面、模块、卡片、列表、按钮组、表单区域等均应优先采用自动布局。

2. **所有尺寸尽量遵循设计规范**
   - 间距、内边距、组件尺寸尽量使用统一的规格。
   - 默认以 **6px 的倍数** 作为基础单位。

3. **避免“看起来对了，但结构不对”**
   - 设计稿不仅要视觉正确，还要层级合理、可编辑、可扩展。
   - 不要为了对齐视觉效果而破坏语义结构。

4. **优先复用组件和样式**
   - 相同的按钮、输入框、标签、卡片等应尽量使用一致结构。
   - 同类元素保持统一的圆角、描边、阴影、字号和间距。

---

## 3. Auto Layout 规则

### 3.1 容器必须使用自动布局
- 画板使用自动布局。
- 页面模块、卡片、列表项、表单项、按钮组等必须使用自动布局。
- 不要用手动摆放替代容器布局。

### 3.2 画板不要裁切内容
- 画板尺寸应能完整容纳全部内容。
- 不允许出现内容超出画板边界、被遮挡或被裁切的情况。

### 3.3 高度自适应内容
- 自动布局高度应随内容增长而变化。
- 不要固定高度导致文本、列表、按钮组超出模块。
- 只有少量特殊场景允许固定高度，例如：
  - 图标
  - 按钮
  - 标签
  - 头像
  - 需要强制统一高度的输入框

### 3.4 间距与边距
- 自动布局的间距、内边距均应为 **6 的倍数**：
  - 6px / 9px / 12px / 18px / 24px / 30px / 36px / 42px / 48px / 60px
- 同一层级内的间距应保持一致，不要混用无规律数值。

### 3.5 对齐方式
- 同类元素应统一对齐方式。
- 标题、正文、按钮、输入框、图标应按设计系统保持一致对齐。
- 不要通过手动微调位置来对齐，优先使用容器布局解决。


### 3.6 蒙层样式
- 在图片上使用蒙层必须按照 linear-gradient(0deg, rgba(0, 0, 0, 0.60) 0%, rgba(0, 0, 0, 0.00) 100%);上浅下深的方式

## 4. 文本规则

### 4.1 文本字体
- 优先使用：`PingFang SC`
- 备用字体：`Alibaba-PuHuiTi`
- Figma 写入文字前必须显式加载字体。优先加载 `PingFang SC`；如果当前 Figma 环境无法加载或写入失败，必须立即 fallback 到 `Alibaba-PuHuiTi`。
- 如果 `PingFang SC` 和 `Alibaba-PuHuiTi` 都不可用，必须暂停并说明缺少可用中文字体，不得静默写入未知字体。

### 4.2 文本宽度
- 文本容器应允许根据内容扩展。
- 长文本区域应优先使用自动布局或固定宽度 + 自动换行。
- 不要把完整文案压缩到超出可读范围。

### 4.3 文本对齐
- 标题、正文、按钮文案、说明文案应保持明确的对齐关系。
- 多列内容中，文字基线尽量统一。

---

## 6. 颜色规则

- 不要通过复杂色彩叠加制造层次。

---

## 7. 间距与尺寸规则

### 7.1 基础间距体系
统一采用以下规范：
- 6px
- 9px
- 12px
- 18px
- 24px
- 30px
- 36px
- 42px
- 48px
- 60px

### 7.2 禁止使用无规律数值
- 不要使用 7px、10px、13px、17px 等非规范值。
- 特殊像素只允许在极少数图标或物理像素对齐场景中使用。

---


## 8. 图标与插图规则

### 8.1 图标来源
所有图标必须使用 agent 项目中的以下目录：
figma-icons
要求：
只能从 figma-icons 目录中选择图标。
不允许 AI 临时绘制图标。
不允许使用 Figma 默认图形临时拼接图标。
不允许使用外部网络图标、第三方图标库或未授权资源。
不允许用 emoji 代替图标。
如果目录中没有完全匹配的图标，应选择语义最接近的图标，并保持样式一致。
如果没有合适图标，应在写入前明确说明缺少图标资源，不要自行创造。

### 8.2 图标写入方式
通过 Figma MCP 写入图标时，应优先：

从 figma-icons 目录读取对应图标文件。
将图标作为 SVG / Vector 导入到 Figma。
保持原始图标比例。
根据组件规范设置统一尺寸。
根据需要应用当前文本色或功能色。
禁止：

拉伸图标导致比例变形。
将图标拆散成不可维护的多个无意义路径。
使用截图或位图替代矢量图标。
手动画矩形、圆形、线条拼成图标。

### 8.3 图标尺寸
- 图标应使用统一尺寸体系：
  - 12px
  - 16px
  - 20px
  - 24px
- 同一模块中尽量不要混用多种图标尺寸。

### 8.4 图标对齐
- 图标与文字之间间距通常使用 6px 或 9px。

### 8.5 插图与占位图
- 插图应保持比例，不要拉伸变形。
- 占位图需遵循统一圆角和背景风格。

---


## 9. 规范化写入流程

### 9.1 写入前检查
- 明确页面类型与目标尺寸
- 明确文本内容和层级
- 明确组件样式与状态
- 明确是否已有可复用组件

### 9.2 写入时原则
- 先搭结构，再填内容，再补样式
- 先大容器，后子模块
- 先统一样式，再做差异化处理

### 9.3 写入后检查
- 是否所有容器都使用了自动布局
- 是否存在内容裁切
- 间距是否符合 6 的倍数
- 文本层级是否正确
- 图层命名是否清晰
- 是否存在无意义的固定尺寸
- 是否存在重复或冲突样式

---

## 10. 禁止项

以下行为禁止出现：

1. 画板裁切内容
2. 容器不使用自动布局
3. 使用大量手动绝对定位
4. 间距和尺寸不符合 6 的倍数体系
5. 文本层级混乱
6. 图层命名无意义
7. 同类组件样式不一致
8. 固定高度导致内容溢出
9. 随意引入新颜色
10. 使用不可维护的嵌套结构
